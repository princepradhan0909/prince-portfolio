# Prince Pradhan — Portfolio

A responsive, single-page portfolio introducing Prince Pradhan, a BCA student
aspiring to become a Java Backend Developer. It presents my background,
technical skills, an independent project, development journey, education, and
contact information.

## Tech stack

- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Simple Icons for technology brand marks
- JavaScript and JSX

The Java and VS Code SVG marks are from Devicon; their MIT license notice is
included in `src/assets/icons/DEVICON-LICENSE.txt`.

- Hero and profile photograph

- Contact
- Footer

## Local development

Install [Node.js](https://nodejs.org/) and npm, then run:

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Build, preview, and lint

```sh
npm run build
npm run preview
npm run lint
```

The production build is written to `dist/`. Run `npm run build` before starting
the local preview server.
